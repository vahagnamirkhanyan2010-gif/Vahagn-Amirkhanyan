# 1. Website ստեղծում




Շաբաթ 1․ Անհատական վեբ էջի կարգավորում և Git-ի հիմունքներ
Առաջին շաբաթվա ընթացքում ես հաջողությամբ կարգավորեցի իմ անձնական ուսումնական վեբ էջը, ծանոթացա ծրագրավորման աշխատանքային գործիքներին և հրապարակեցի իմ առաջին նախագիծը GitHub-ում։

1. Գործիքների տեղադրում և աշխատանքային միջավայր (Setup)
VS Code-ի տեղադրում: Ներբեռնեցի և տեղադրեցի Visual Studio Code կոդի խմբագրիչը։

Նախագծի ֆայլերի բացում: Ներբեռնեցի Fab Lab-ի կայքի նախագծային ZIP ֆայլը, ապապակեպարտեցի (unzip) այն և բացեցի Visual Studio Code-ում։

Git Bash-ի ինտեգրում: VS Code-ի ներքին տերմինալում (Terminal) որպես հիմնական միջավայր ընտրեցի Git Bash-ը։

2. Անձնական տվյալների կարգավորում (Git Config)
Տերմինալի միջոցով Git-ին ներկայացրեցի իմ ինքնությունը, որպեսզի իմ կատարած բոլոր փոփոխությունները կապվեն իմ GitHub հաշվի հետ․

Կարգավորեցի էլ. հասցեն․ git config --global user.email "im-email@example.com"

Կարգավորեցի օգտանունը․ git config --global user.name "Vahagn Amirkhanyan"

3. Կայքի բովանդակության թարմացում և թարգմանություն (Content & Translation)
Գլխավոր էջ (index.md): Անգլերեն նախնական տեքստերը թարգմանեցի հայերենի՝ ավելացնելով իմ նպատակներն ու ուսումնական ծրագիրը։

«Իմ մասին» էջ (docs/about/index.md):

Ջնջեցի նախկին ուսանողի տվյալները։

Ավելացրեցի իմ անձնական նկարագրությունը (անունը, ծննդավայր Վանաձորը, հետաքրքրությունները՝ ֆուտբոլ, պատմություն, շախմատ և հասարակագիտություն)։

Ավելացրեցի իմ լուսանկարը images/ պապկայում և կապեցի Markdown կոդով․

![My Photo](../images/Nkar.jfif)

«Վերջնական պրոյեկտ» էջ (docs/projects/final-project.md): Ավելացրեցի իմ ապագա նախագծի ձեռքով պատկերված սևագիրը (sketch) և նկարագրությունը։

4. Code Preview և local փորձարկում
VS Code-ի ներսում օգտագործեցի Markdown Preview (Ctrl + Shift + V) գործիքը՝ տեքստի, նկարների և հղումների ճիշտ արտացոլումը ստուգելու համար։

Ծանոթացա MkDocs Material թեմայի կառուցվածքին (mkdocs.yml), որը պատասխանատու է կայքի արտաքին տեսքի, գույների և մենյուների համար։

5. GitHub Pages-ի սազացում և կայքի հրապարակում (Deployment)
Git Հրամաններ: Կատարված բոլոր փոփոխությունները պահպանեցի և ուղարկեցի GitHub repository հետևյալ քայլերով․

Bash
git add .
git commit -m "Update About Me, Final Project sketch, and Armenian translations"
git push origin main
GitHub Actions & Pages Խնդրի լուծում:

Կարգավորեցի GitHub repository-ի Settings > Pages բաժինը՝ ընտրելով GitHub Actions աղբյուրը։

Settings > Actions > General բաժնում ակտիվացրեցի Read and write permissions իրավունքները, ինչը վերացրեց 404 (HttpError) սխալը և հաջողությամբ գործարկեց կայքի առցանց հղումը։
