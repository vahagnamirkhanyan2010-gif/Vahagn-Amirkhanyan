# 1. Website ստեղծում




Ահա ձեր կատարած ողջ աշխատանքի մանրամասն փաստաթղթավորումը (դոկումենտացիան)՝ ներառելով ձեր տված հարցերն ու հարցումները (prompts)․

Շաբաթ 1․ Անհատական վեբ էջի կարգավորում և Git-ի հիմունքներ
Առաջին շաբաթվա ընթացքում ես հաջողությամբ կարգավորեցի իմ անձնական ուսումնական վեբ էջը, ծանոթացա ծրագրավորման աշխատանքային գործիքներին և հրապարակեցի իմ առաջին նախագիծը GitHub-ում։

1. Գործիքների տեղադրում և աշխատանքային միջավայր
VS Code-ի տեղադրում: Ներբեռնեցի և տեղադրեցի Visual Studio Code կոդի խմբագրիչը։

Նախագծի ֆայլերի բացում: Ներբեռնեցի Fab Lab-ի կայքի նախագծային ZIP ֆայլը, ապապակեպարտեցի (unzip) այն և բացեցի Visual Studio Code-ում։

Git Bash-ի ինտեգրում: VS Code-ի ներքին տերմինալում (Terminal) որպես հիմնական միջավայր ընտրեցի Git Bash-ը։

Իմ հարցումը (Prompt):

«how to open bash in terminal in vscode»

(Ինչպե՞ս բացել Bash-ը VS Code-ի տերմինալում)

2. Անձնական տվյալների կարգավորում (Git Config)
Տերմինալի միջոցով Git-ին ներկայացրեցի իմ ինքնությունը, որպեսզի իմ կատարած բոլոր փոփոխությունները կապվեն իմ GitHub հաշվի հետ․

Կարգավորեցի էլ. հասցեն․ git config --global user.email "im-email@example.com"

Կարգավորեցի օգտանունը․ git config --global user.name "Vahagn Amirkhanyan"

3. Կայքի բովանդակության թարմացում և թարգմանություն
Գլխավոր էջ (index.md): Անգլերեն նախնական տեքստերը թարգմանեցի հայերենի՝ ավելացնելով իմ նպատակներն ու ուսումնական ծրագիրը։

«Իմ մասին» էջ (docs/about/index.md):

Ջնջեցի նախկին ուսանողի տվյալները։

Ավելացրեցի իմ անձնական նկարագրությունը (անունը, ծննդավայր Վանաձորը, հետաքրքրությունները՝ ֆուտբոլ, պատմություն, շախմատ և հասարակագիտություն)։

Ավելացրեցի իմ լուսանկարը images/ պապկայում և կապեցի Markdown կոդով․

![My Photo](../images/Nkar.jfif)

«Վերջնական պրոյեկտ» էջ (docs/projects/final-project.md): Ավելացրեցի իմ ապագա նախագծի ձեռքով պատկերված սևագիրը (sketch) և նկարագրությունը։

4. Կայքի արտաքին տեսքի հասկացումը (Code Preview)
Ծանոթացա MkDocs Material թեմայի կառուցվածքին (mkdocs.yml), որը պատասխանատու է կայքի արտաքին տեսքի, գույների և մենյուների համար։

Հասկացա տարբերությունը տեղային (local) Markdown ֆայլերի և վեբում հավաքված (build եղած) HTML կայքի միջև։

Իմ հարցումը (Prompt):

«I have a project on GitHub and VS Code with MkDocs material theme... I want to understand why my website interface, colors, background, and fonts look like this. How is this generated, and what is the difference between my local extracted files/folders and the .zip file?»

(Ինչո՞ւ է իմ կայքի տեսքը փոխվում, և որն է տարբերությունը local ֆայլերի ու .zip-ի միջև)

5. GitHub Pages-ի սազացում և deployment-ի սխալների լուծում
GitHub Actions-ի միջոցով կայքը հրապարակելիս առաջացավ status 404 HttpError սխալ։

Իմ հարցումը (Prompt):

«Error: Creating Pages deployment failed... Error: HttpError: Not Found... here is my error. What is wrong with my site because in preview is working well, but my website is erroring»

(Ահա իմ սխալը, ինչո՞ւ է տեղում preview-ն աշխատում, իսկ օնլայն կայքը՝ սխալ տալիս)

Խնդրի լուծումը․

Repository-ի Settings > Pages բաժնում աղբյուրը (Source) փոխեցի GitHub Actions-ի։

Settings > Actions > General բաժնում ակտիվացրեցի Read and write permissions իրավունքները։

6. Նոր թղթապանակի և ֆայլերի ավելացում (Git Push)
Կայքի նոր տարբերակը կամ թղթապանակը GitHub ուղարկելու համար կիրառեցի Git-ի հիմնական հրամանները․

Իմ հարցումը (Prompt):

«I have created new folder how to add to add this version of my website»

(Ես ստեղծել եմ նոր թղթապանակ, ինչպե՞ս ավելացնել կայքի այս տարբերակը)

Bash
git add .
git commit -m "Add new folder and site content"
git push origin main
